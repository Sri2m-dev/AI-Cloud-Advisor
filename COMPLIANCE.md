# Compliance & Security Checklist

Track your compliance and security features phase by phase. Mark each as Not started / In progress / Complete.

## Phase 1 — Compliance Foundation
- [ ] Privacy Policy page published and linked in UI
- [ ] Terms of Service page published and linked in UI
- [ ] Cookie consent banner implemented
- [ ] Data residency (EU) documented and enforced
- [ ] Contact/support link in footer

## Phase 2 — Architecture Upgrade
- [ ] FastAPI backend created
- [ ] API authentication (JWT/OAuth2) enabled
- [ ] API docs (Swagger/OpenAPI) available
- [ ] Audit logging for all sensitive actions
- [ ] Rate limiting/abuse protection

## Phase 3 — Enterprise SaaS
- [ ] SSO (Azure AD, SAML/OAuth2) integrated
- [ ] Stripe billing (plans, usage, dunning)
- [ ] Tenant isolation (row-level security/tests)
- [ ] Automated cross-tenant access tests

## Phase 4 — Enterprise Grade
- [ ] Dockerized deployment
- [ ] Kubernetes/Helm support
- [ ] Incident response plan documented
- [ ] Security policy documented
- [ ] Penetration testing scheduled/completed
- [ ] SOC2/ISO 27001 readiness

---
Update this file after each phase and during audits.
