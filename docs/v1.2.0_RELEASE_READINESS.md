## Hosted workflow correction

- `background-jobs-cron.yml`: corrected YAML block indentation for the embedded Python. It no longer creates a filename-named zero-job failure on feature pushes.
- `cd.yml`: replaced the unsupported direct `secrets` condition with a shell-level optional webhook check. It no longer creates a zero-job failure on feature pushes.
- `ci.yml`: added the release-candidate branch push trigger and standardized every test invocation on `python -m pytest` for a deterministic repository import path on Ubuntu.

CD and Background Jobs were not manually dispatched because they can publish images, invoke deployment webhooks, or run secret-backed operational mutations. Their valid trigger behavior was verified by GitHub accepting the definitions and not launching them for the feature push.
