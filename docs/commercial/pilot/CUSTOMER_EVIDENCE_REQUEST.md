# Nexora Customer Evidence Request

## Purpose

This document defines the preferred customer evidence for a Zero-Access Nexora pilot.

Only information approved for the agreed pilot scope should be supplied.

## Preferred Evidence

### Organization / Cloud Accounts

Preferred information:

- account identifier;
- account name;
- business or organizational unit;
- account status;
- environment where available.

### Technology / Resource Inventory

Preferred information:

- resource identifier;
- resource type;
- cloud account;
- region;
- application;
- environment;
- owner;
- cost center;
- business unit.

### Cost / Billing Export

Preferred information:

- billing period;
- usage date;
- cloud account;
- cloud service/product;
- resource identifier where available;
- usage information;
- cost;
- currency;
- application tag;
- environment tag;
- cost-center tag.

### Application / Business Mapping

Preferred information:

- application;
- business service;
- cloud account;
- owner;
- criticality where available.

## Optional Evidence

Where approved and relevant:

- CMDB exports;
- architecture inventories;
- SaaS/license inventories;
- ownership mappings;
- cost-center mappings;
- service catalog information;
- approved security/compliance evidence.

## Data Minimization

Do not provide:

- passwords;
- access keys;
- secret keys;
- private keys;
- session tokens;
- credentials embedded in files;
- unnecessary personal information.

Provide only evidence required for the agreed pilot objective.

## Evidence Quality

Nexora may identify:

- unknown accounts;
- cost resources not represented in inventory;
- inventory resources without cost;
- incomplete classification;
- missing billing periods;
- untagged resources;
- inconsistent ownership;
- evidence coverage gaps.

These may be valid pilot findings rather than ingestion failures.

## Zero-Access Model

Zero-Access Evidence Import does not require Nexora to receive direct customer cloud credentials.

Customer-approved exports are processed through Nexora's governed evidence path.
