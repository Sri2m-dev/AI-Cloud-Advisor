## Security Contract

- Customer long-lived AWS access keys are not required.
- Commercial Connected Mode requires an IAM Role ARN.
- External ID is generated by Nexora.
- External ID is supplied to STS AssumeRole.
- STS session duration is bounded to 3600 seconds.
- Temporary STS credentials remain within the in-memory session contract.
- Assumed AWS account identity is checked against the Role ARN account.
- AWS provider errors are sanitized.
- Customer onboarding permissions remain read-only.
- AWS Access Key / Secret Access Key fields are absent from the commercial UI.
- Existing internal/default boto3 compatibility remains separate from commercial Connected Mode.
