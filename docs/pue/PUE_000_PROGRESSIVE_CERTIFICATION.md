# PUE-000 Progressive Certification

## Parallel migration

The current prospect flow remains authoritative throughout PUE development. PUE receives the same
authorized source through the existing security boundary and initially produces observational
artifacts only.

| Stage | PUE mode | Authority |
| --- | --- | --- |
| A | Structural profile | Existing prospect flow only |
| B | Semantic discovery shadow comparison | Existing prospect flow only |
| C | Governed normalization comparison | Existing prospect flow only |
| D | Query capability/result comparison | Existing prospect flow only |
| E | Explicitly selected capabilities | Requires authority migration approval |

No comparison result silently changes the current analysis, currency provenance, session bridge,
workspace isolation, Ask Nexora answer, or Return-to-Demo behavior.

## Certification gates

| Gate | Required outcome |
| --- | --- |
| PUE-C0 | Architecture contracts, isolation, provenance, and non-goals approved |
| PUE-C1 | Structural profiling certified as factual, reproducible, safe, and format-bounded |
| PUE-C2 | Semantic classification accuracy, ambiguity, taxonomy, and drift controls certified |
| PUE-C3 | Confirmation RBAC, audit, scope, override, and expiry behavior certified |
| PUE-C4 | Dynamic normalization provenance, reversibility, comparison, and units certified |
| PUE-C5 | Coverage, aggregation, query sufficiency, and evidence-bound answers certified |
| PUE-C6 | Multi-file identity governance, conflict handling, and fusion lineage certified |
| PUE-C7 | Prospect workflow authority migration explicitly approved |

Each gate requires tenant/prospect isolation, retention/purge, security, regression, and backward
compatibility evidence. A failed comparison preserves the existing authoritative path.

## PUE-001 entry recommendation

Authorize PUE-001 only after PUE-C0 review. PUE-001 should implement structural/factual profiling in
shadow mode for bounded CSV/XLSX inputs, with safe sampling and anomaly reporting. It must not emit
semantic concept IDs, provider/service conclusions, normalized evidence, aggregates, or application
answers. Certification should compare reproducibility, resource bounds, privacy behavior, format
handling, and lifecycle cleanup without changing the current prospect result.
