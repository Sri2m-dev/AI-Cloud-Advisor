# NEXORA V1 API Database Object Register

**Disposition: BLOCKED — no missing object was implemented.**

## Classification basis

The 29-object set is the distinct set of names in
`docs/cmp/CMP-P6-DEF-001/schema_inventory.json`
`missing_literal_call_definitions`. The inventory records caller paths and
PostgREST operations, but does not itself establish authoritative DDL.
`docs/cmp/CMP-P6-SC-001/application_schema_contract.md` supplies the earlier
contract dispositions. Its eight `V1_REQUIRED` objects include two names in
this current set; the other six remain separate unresolved blockers.

The route classification in
`docs/release/nexora-v1-m0-2026-11-07/route_catalogue.csv` is proposed, not an
enforced access policy. M0 says navigation is broader and direct-route
restriction remains work. Therefore “reachable” below means that a current
caller or route exists, not that it is certified for release.
