[API object register](../nexora-v1-api-contract-closure-2026-11-12/API_OBJECT_REGISTER.md)
against the route profile implemented in this task.

- **SQL objects defined or resolved:** 0. No speculative DDL was added.

  (`approval_requests`, `approval_history`). The functional requirement now
  uses the existing append-only customer-workflow event contract.

  routes, but their semantics/contracts remain unresolved.
- Three unknown cost objects remain reachable through the supported-candidate
  Cost Intelligence page. Other unknown object contracts remain open even
  where their current routes are excluded.
- The original inventory categories (2 required, 1 supporting, 19 deferred,
  7 unknown) describe the pre-consolidation call sites. In the active workflow,
  the two legacy approval relations are no longer required; this does not
  resolve other schema gaps or certify the full V1 database.
